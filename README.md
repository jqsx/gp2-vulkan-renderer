# GP2 Vulkan Renderer - Franciszek Rakowiecki
https://github.com/Howest-DAE-GD/gp2-vulkan-renderer-FranciszekRakowiecki

A vulkan renderer made for the Graphics Programming 2 course. Includes BRDF physically based rendering, Directional lights and Point lights. 
Uses GLSL as the shading program, uses GLTF in order to load the Sponza scene. Supports normal mapping, roughness and metalic as texture inputs.
